## 🎨 Design Highlights

- **Typography:** Playfair Display (headings) + Poppins (body)
- **Color Palette:** Warm orange `#FF6B2B` accent on light/dark backgrounds
- **CSS Variables:** Entire theme controlled via `:root` and `[data-theme="dark"]`
- **Animations:** CSS keyframes for floating, fade-in, and slide-in effects
- **No framework JS** — pure vanilla JavaScript for all interactivity

<br>

## 📸 Sections Overview

### 🏠 Hero Section
Large food banner with animated floating badges, heading, tagline, CTA buttons, and key stats (250+ dishes, 15K+ customers, 4.9★ rating, 30-min delivery).

### 🍕 Popular Food
Six food cards rendered dynamically from a JavaScript data array. Each card includes an image, tag badge, favourite toggle, star rating, price, and Add to Cart button.

### 📋 Menu with Category Filter
16 menu items across 4 categories. Clicking a filter button instantly updates the grid without any page reload.

### ⭐ Customer Reviews
Six testimonial cards with avatar initials, star rating, review text, and customer name/role.

### 🛒 Cart Sidebar
A smooth slide-in cart with quantity +/- controls, total calculation, and an order confirmation toast.

### 🌙 Dark Mode
Full theme switch using CSS custom properties — no flickering, no JavaScript class gymnastics.
